# HCM Lite — Hackathon Website

A static Human Capital Management demo built with HTML, CSS, and Bootstrap. No JavaScript or backend is used.

## View the website

Open `index.html` in a browser. Choose Admin or Employee, then use the relevant login form with any demo email and password to open that role's dashboard.

The signup confirmation, employee records, attendance, leave requests, settings, and payslips are sample UI data. Forms do not save changes, and role navigation is not real access control.
